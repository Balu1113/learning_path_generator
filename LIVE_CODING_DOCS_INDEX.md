## 📋 Checklist for Setup

- [ ] Read LIVE_CODING_FINAL_SUMMARY.md
- [ ] Get Judge0 API key from RapidAPI
- [ ] Set JUDGE0_API_KEY in .env
- [ ] Run `python manage.py migrate`
- [ ] Run `python manage.py seed_code_challenges`
- [ ] Start backend: `python manage.py runserver 8001`
- [ ] Start frontend: `npm run dev`
- [ ] Visit http://localhost:5174/study
- [ ] Test a challenge
- [ ] Read LIVE_CODING_CHALLENGES.md for details
